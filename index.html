How it works

A supervisor orchestrates four specialist agents in sequence, each reading prior findings from DynamoDB before adding its own analysis.

👁
Supervisor
Routes the pipeline and decides execution order using the LLM.
🔐
Security Agent
First to run. Scans diff for vulnerabilities and writes security_findings.
writes → security_findings
🧹
Code Quality Agent
Reads security findings, then checks style, complexity, and best practices.
reads → security_findings
📋
PR Reviewer Agent
Reads both prior findings to produce a holistic PR review with context.
reads → security + quality
📊
Summary Agent
Aggregates all findings into a scored report and saves a lineage trace.
writes → summary_report + lineage_run
Score formula
score = 10 − (CRITICAL × 5 + HIGH × 2 + MEDIUM × 1 + LOW × 0.5)
A CRITICAL finding sets should_block = true.

What you get

Everything needed for automated, agent-driven PR reviews — local or cloud.

🤖
LangGraph Multi-Agent
Supervisor + specialist agents with shared DynamoDB memory. LLM decides execution order dynamically.
☁️
Flexible LLM Backends
Runs on Ollama (local), Docker Model Runner, or AWS Bedrock (Claude Haiku). Switch with one env var.
🔒
Cognito Auth
OAuth2 login via AWS Cognito Hosted UI with RS256 JWT validation. Invite-only access with admin controls.
📐
Data Lineage
Per-run agent trace stored in DynamoDB and surfaced in the web UI sidebar for full auditability.
🪝
GitHub Integration
Fetches PR diffs via GitHub API. Optionally posts review comments back — token-gated, HMAC-verified webhooks.
📊
Evaluation Framework
Offline, shadow, and online evaluation modes with thumbs-up/down feedback and aggregate metric gauges.
